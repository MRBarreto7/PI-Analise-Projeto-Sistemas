# PI — Parte 3: Arquitetura e Diagramas UML

Projeto: **Sistema de Gestão de TCC**.

Integrantes: Diogo Alex Marquardt, Wilhelm Niemeyer Bock, Bruno Comassetto e Matheus Rocha Barreto.

## Conteúdo
- `Documento_Arquitetura_Parte_3.pdf`: documento principal.
- `diagramas/*.png`: imagens para consulta.
- `diagramas/*.dot`: fontes editáveis no Graphviz.

## Visualizar/editar
Abra o PDF ou as imagens diretamente no GitHub. Para atualizar um diagrama instale Graphviz e execute, por exemplo: `dot -Tpng diagramas/02_classes.dot -o diagramas/02_classes.png`.

## Atenção antes da entrega
O enunciado disponível informa apenas “Documento de Arquitetura + Diagramas UML”; não especifica quais diagramas são obrigatórios. A Parte 2 contém divergências sobre o momento de composição da banca. O documento registra a decisão sugerida. O gráfico de sequência é uma representação de mensagens, não a notação formal de lifelines UML.
